This portfolio demonstrates practical, hands-on engineering across Enterprise IT Support, Desktop Management, and Infrastructure Administration. The lab simulates real-world helpdesk, systems, and network support scenarios—focusing on centralized identity management, user account provisioning, endpoint security troubleshooting, and network layer availability.

Tier-2/Tier-3 IT Support Competencies Showcased:
Active Directory Administration: User onboarding, bulk account provisioning, group policy object (GPO) enforcement, and domain-wide password reset/security baseline management.
Endpoint Management & RMM (Action1): Conducting real-time host diagnostics, identifying hardware resource bottlenecks, managing software compliance audits, and deploying automated patch remediation across the enterprise fleet.
Desktop & Storage Support: Hardware-level provisioning via Generation 2 Hyper-V environments, local system restore recovery configuration, and managing secure file distributions with custom network file sharing permissions.
Network Infrastructure Troubleshooting (Cisco Packet Tracer): Isolating department broadcast domains via VLAN database configurations, validating default gateway routing paths, and monitoring physical line-protocol interface stability.
